## 🎚️ 자막을 영상에 입히려면

영상은 이미 무음으로 녹화되어 있습니다. 자막이나 음성을 추가하려면 ffmpeg 한 줄로 가능:

### 자막 입히기 (.srt 파일)

먼저 `demo/subtitles.srt` 같은 자막 파일을 만든 뒤:

```bash
cd /Users/heoujin/ai-office-agents/demo
ffmpeg -i video/ai-office-demo.mp4 \
  -vf "subtitles=subtitles.srt" \
  -c:a copy video/ai-office-demo-subtitled.mp4
```

### 보이스오버 입히기

먼저 위 보이스오버 텍스트를 mac 의 `say` 명령으로 mp3 만들기:

```bash
say -v Yuna -o demo/voiceover.aiff -f demo/voiceover-text.txt
ffmpeg -i demo/voiceover.aiff demo/voiceover.mp3

# 영상에 오디오 합치기
ffmpeg -i video/ai-office-demo.mp4 -i demo/voiceover.mp3 \
  -c:v copy -c:a aac -shortest \
  video/ai-office-demo-narrated.mp4
```

> 💡 `say -v ?` 로 사용 가능한 음성 목록을 보세요. 한국어 음성은 `Yuna`, `Junseong` 등이 있습니다.

설정을 바꾸거나 다시 찍어야 할 때:

## ✏️ 영상 스크립트 작성 팁

이 데모를 한국어/영어로 다시 녹음한다면:

- **한국어 보이스오버**: macOS `say -v Yuna` (여성), `say -v Junseong` (남성)
- **영어 보이스오버**: `say -v Samantha`, `say -v Alex`
- **속도**: `say -r 180` 정도가 자연스러움 (기본 175, 한국어는 더 빠르게)

자막 타이밍은 영상 길이가 약 120초이므로:
- 한 자막당 5–10초 권장
- `00:00:00,000 --> 00:00:05,000` 식의 SRT 포맷
